# DAQ Control 설치 파일

## 다운로드

**[최신 버전 다운로드](https://github.com/kimtj12/daq-control-releases/releases/latest)**

| 파일 | 대상 OS |
|---|---|
| `DAQ-Control_<버전>_Win10_x64-setup.exe` | Windows 10 / 11 |
| `DAQ-Control_<버전>_Win7_x64-setup.exe` | Windows 7 |

## 설치

1. 위 링크에서 PC의 Windows 버전에 맞는 파일을 받습니다.
2. 받은 `.exe`를 실행합니다. 인터넷이 없는 PC에서도 설치할 수 있습니다.
3. "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**을 누릅니다. 코드 서명이 없는 내부 배포용 프로그램이라 이 창이 뜹니다.
